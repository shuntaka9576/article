5月の振り返りです！

4月につづき5月の振り返りをやっていきます！

かき氷をたくさん食べた！

![img](https://res.cloudinary.com/dkerzyk09/image/upload/v1780613494/blog/20260601-poem/nzf7kb2hzyixo4ccdzg5.png)

あと出張で初めて福岡に行きました！仕事だったので、うどん、もつ鍋などご飯を楽しむ感じでしたが...😆業務は動画関連のAIエージェント、RAGや駆動開発周りを引き続きやっていた。いつも通りこちらは個人の活動をメインに。

5月もagentoastをコツコツ改善してました。

https://github.com/shuntaka9576/agentoast

- Vimライクのキーバインド実装
  - `gg`/`G` でリスト先頭・末尾へジャンプ
  - vim ライクなファジー検索を追加
  - パネルヘッダーを固定し `hjkl`/矢印キーで Apps ビューをナビゲート
- tmux遷移改善
  - `t` キーで現在の tmux ペインに直接ジャンプ
  - 通知なしでパネルを開いたとき実際の tmux ペインにフォーカスを当てる
- 状態検出バグフィックス
  - Claude Code がフォークを spawn するときの running 状態を正しく検出
  - Copilot CLI の "esc cancel" ヒント表示による実行状態検出を修正
  - Claude モードラインのカウンタをトレイリングヒント付きでパース
- その他
  - [issue対応](https://github.com/shuntaka9576/agentoast/issues/267) opencode の notify プラグインが `/tmp` に際限なくデバッグログを書き出すのを修正

地味な修正が多いですが、自分が毎日使うものなので違和感をつぶすのが楽しい。

ちょうどこの時期 agmsg というエージェント同士がターミナルをまたいでメッセージをやり取りする手法が界隈で流行っていました。agentoast にも `send-keys` サブコマンドを実装しました。ペイン IDを指定して別ペインのエージェントにメッセージを届けれます！つまりエージェント間で5目並べが出来ます！

https://x.com/shuntaka_jp/status/2061465965528076328?s=20

楽しいですね〜

zenn-dev/zenn-editor の `:::message` の中に `:::details` を書いたとき、その中の URL がカード化されない問題（[#658](https://github.com/zenn-dev/zenn-editor/issues/658)）の修正しました。

https://github.com/zenn-dev/zenn-editor/pull/659

他にも改善したい項目があるので可能な限り提案をして行きたいです...!

microsoft/apm が [#1055](https://github.com/microsoft/apm/pull/1055) user scopeで少し実装に漏れがあったので修正しました。ただ結局user scopeは自分の場合apmのインストール速度の律速がつらくてnixにしている。
5月はそこそこブログ書いてました！一番ブログ書いていた時期と同じ本数なので。後半も頑張りたい...ただ多分難しい気がする。。

https://dev.classmethod.jp/articles/shuntaka-claude-code-tmux-personal-tips/

https://dev.classmethod.jp/articles/shuntaka-apm-agent-skills-renovate/

TanStackのサプライチェーン攻撃を受けて、GitHub Actionsを公開している結構リスクがあるなということでいくつかブログを執筆しました。ここら辺の対策の自分のOSSでも対策入れています。

https://dev.classmethod.jp/articles/shuntaka-zizmor-github-actions-audit/

Code Scaninngとの連携は正直なところ、Actionsのyamlを修正していないPRでもこのCIが通っている必要があり、GITHUB_TOKENで作成されたPRだと仕様上無限ループしないようにCIが実行されないので少し手間が増えた気がします。tagprなのですがGitHub Apps経由でPR作るように変更出来るはず...?試してみます。

https://dev.classmethod.jp/articles/shuntaka-zizmor-sarif-code-scanning/

GitHub Copilot CLIについてLTしました。この会はかなり盛り上がっていて、GitHub Copilotユーザーの層の厚さを感じました！とはいえ料金面などまだまだ悲しみが多いので頑張ってほしいところです。

https://dev.classmethod.jp/articles/shuntaka-github-copilot-cli-lt-night-skill-management/

7月末から育休なので、基本的には準備で個人開発は完全に止まりそうです。。AIコーディングエージェントはどうやら巷ではPMFしたと言われ、計算資源の影響から従量制への移行が進むと思われます。このような事例が各業界で起こるんでしょうね。。トークンマキシングからマネジメントへ。
